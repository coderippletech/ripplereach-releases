## Install

**Windows**

1. Download `RippleReach_x.y.z_x64-setup.exe` from the [latest release](https://github.com/coderippletech/ripplereach-releases/releases/latest)
2. Run it. It installs for your account, without administrator rights
3. The Windows build isn't code-signed yet, so SmartScreen may warn you the first time: choose **More info → Run anyway**

**macOS**

1. Download `RippleReach_x.y.z_aarch64.dmg` (Apple silicon) or `RippleReach_x.y.z_x64.dmg` (Intel) from the [latest release](https://github.com/coderippletech/ripplereach-releases/releases/latest)
2. Open it and drag **RippleReach** into **Applications**
3. To reach this Mac from your other computers, open **Share this Mac** in RippleReach and allow Screen Recording and Accessibility for **RippleReach Host** when macOS asks

Every macOS build is signed with a Developer ID certificate and notarized by Apple.

RippleReach keeps itself up to date: it checks for new versions in the background, downloads them quietly, and asks before it restarts.

## Requirements

- Windows 10 or 11, 64-bit
- macOS 14 Sonoma or later, on Apple silicon or Intel
